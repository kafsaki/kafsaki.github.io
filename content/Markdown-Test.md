## 代码

### 行内代码
使用 `console.log('Hello')` 输出。

### 围栏代码块（带语言标识）
```javascript
function greet(name) {
    return `Hello, ${name}!`;
}
console.log(greet('World'));
```

```python
def greet(name):
    return f"Hello, {name}!"
print(greet("World"))
```
